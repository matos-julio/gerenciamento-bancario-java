# Gerenciamento Bancário em Java

## Descrição
Esse projeto foi criado como parte de um projeto da Materia Linguagem Orientada a Objetos, da Universidade Anhanguera.

Este projeto implementa um sistema de gerenciamento bancário em Java, permitindo que o usuário:
- Cadastre seu nome, sobrenome e CPF
- Consulte saldo
- Realize depósitos e saques

## Como executar
1. Clone o repositório.
2. Compile e execute o código na sua IDE ou no terminal.

## Estrutura do código
- **Classe GerenciaBanco**: Responsável pela execução do menu e interação com o usuário.
- **Classe Cliente**: Responsável pelo gerenciamento dos dados do cliente e operações bancárias.
